Build a Proof of Concept (POC) for a **Digital Employee ID Card system using QR codes**.

## Goal

The system should allow an admin to create an employee profile, generate a unique QR code for that employee, and when the QR code is scanned, open a digital employee ID card displaying that employee's information.

The main flow is:

Admin → Create Employee → Save to MongoDB → Generate QR → Scan QR → Digital Employee ID Card

## Tech Stack

Use:

* Frontend: React + Vite
* Backend: Node.js + Express.js
* Database: MongoDB + Mongoose
* QR generation: `qrcode` npm package
* Styling: Tailwind CSS
* API communication: Axios

Do NOT add authentication, Redis, cloud storage, or other advanced infrastructure in the first version. Keep this as a simple working POC.

## Employee Data

Create an Employee model with:

```json
{
  "employeeId": "EMP1001",
  "name": "Ayush Kawane",
```

Make `employeeId` unique.

Use an automatically generated employee ID when creating a new employee.

## Backend APIs

Create these APIs:

### Employee APIs

```text
POST   /api/employees
GET    /api/employees
GET    /api/employees/:employeeId
PUT    /api/employees/:employeeId
DELETE /api/employees/:employeeId
```

### QR API

```text
GET /api/employees/:employeeId/qr
```

This endpoint should generate a QR code containing the frontend URL:

```text
http://localhost:5173/id/:employeeId
```

For example:

```text
http://localhost:5173/id/EMP1001
```

Return the QR code in a format that the React frontend can display.

### Public Digital ID API

Create:

```text
GET /api/id/:employeeId
```

This endpoint should return only the employee information required for the public digital ID card.

Do not expose sensitive database fields.

## Frontend Pages

Create the following pages.

### 1. Admin Dashboard

Route:

```text
/admin
```

Display a table containing:

* Employee ID
* Name
* Designation
* Department
* Status
* View
* Generate QR

Add an:

```text
+ Add Employee
```

button.

### 2. Add Employee

Route:

```text
/admin/employees/new
```

Create a form containing:

* Name
* Email
* Phone
* Company
* Designation
* Department
* Reporting Head
* Office Address
* Photo
* Status

After submitting, create the employee through the backend API.

Show the generated employee ID after successful creation.

### 3. Employee Digital ID

Route:

```text
/id/:employeeId
```

This page is the main feature of the POC.

When someone scans the QR code, this page should open and fetch the employee information from:

```text
GET /api/id/:employeeId
```

Display a professional digital employee ID card.

## Environment Variables

Backend `.env`:

```env
PORT=5000
MONGO_URI=mongodb://localhost:27017/employee-id
FRONTEND_URL=http://localhost:5173
```

Use `FRONTEND_URL` when generating QR URLs instead of hardcoding the frontend URL throughout the code.
