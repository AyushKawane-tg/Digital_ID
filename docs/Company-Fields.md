# Company Fields

## Company Profile

| Field | Description |
|---|---|
| name | Company name |
| logo | Company logo |
| about | Company description |
| website | Official company website |
| corporate_address | Corporate office address |
| contact_number | Company contact number |
| contact_email | Company email |
| ceo_name | CEO name |
| founder_name | Founder name |
| mission | Company mission |
| vision | Company vision |
| company_deck | Company presentation/deck |

## Company Locations

Each location contains:

- Location name
- Address
- Contact number

## Badges and Certificates

Each badge contains:

- Title
- Description
- Image

## Company Deck

The company deck can be uploaded by the administrator and made available from the digital card.
