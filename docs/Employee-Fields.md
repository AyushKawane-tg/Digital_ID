# Employee Fields

## Required Fields

| Field | Required | Description |
|---|---|---|
| employee_id | Yes | Unique employee identifier |
| full_name | Yes | Employee full name |
| designation | Yes | Employee designation |
| department | Yes | Department / Business Unit |
| official_email | Yes | Official company email |
| contact_number | Yes | Employee contact number |
| emergency_contact | Yes | Emergency contact |
| office_location | Yes | Employee office location |
| linkedin_url | Yes | LinkedIn profile |
| date_of_birth | Yes | Employee date of birth |

## Optional Fields

| Field | Required | Description |
|---|---|---|
| picture | No | Employee profile picture |
| instagram_url | No | Instagram profile |
| facebook_url | No | Facebook profile |
| blood_group | No | Employee blood group |

## Card Information

The following information can appear on the digital card:

- Employee picture
- Full name
- Designation
- Department
- Employee ID
- Email
- Contact number
- Emergency contact
- Office location
- LinkedIn
- Instagram
- Facebook
- Blood group
- Date of birth
- QR code
