# Employee Import Template

This Excel template is used by the TeleGlobal Digital Card Platform to import employee records.

## Required Columns

The following columns are mandatory:

| Column | Required |
|---|---|
| employee_id | Yes |
| full_name | Yes |
| designation | Yes |
| department | Yes |
| official_email | Yes |
| contact_number | Yes |
| emergency_contact | Yes |
| office_location | Yes |
| linkedin_url | Yes |
| date_of_birth | Yes |

## Optional Columns

| Column | Required |
|---|---|
| instagram_url | No |
| facebook_url | No |
| blood_group | No |
| picture | No |
